Particle Emitter Chaining Prototype

PixiJS-powered seed for chaining triggers between particle emitters.

This prototype swaps the 2D canvas renderer for PixiJS while keeping the lightweight chaining mechanic. Each emitter registers "chain links" that run when its particles expire, spawning follow-up emitters or short bursts.

Run locally: serve the repo (e.g. cd prototypes/particle-chains && python -m http.server 8000), then open http://localhost:8000/prototypes/particle-chains/index.html in your browser.

  • chain: [burst] — one-shot burst from the particle's last position.
  • chain: [followEmitter] — spawns a temporary emitter that keeps emitting while it lives.
  • Probabilities allow partial chaining so the scene is not uniform.
